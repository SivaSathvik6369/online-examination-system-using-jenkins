# Online Examination System (Jenkins CI/CD Enabled)

A robust examination portal integrated with a Jenkins Declarative Pipeline for continuous integration and automated testing.

## Jenkins Pipeline Setup
1. Open Jenkins Dashboard -> New Item -> Pipeline.
2. Under Pipeline Definition -> Pipeline script from SCM.
3. SCM: Git -> Repository URL: https://github.com/SivaSathvik6369/online-examination-system-using-jenkins.git
4. Branch: */main -> Script Path: Jenkinsfile
5. Click 'Build Now'.
